# Keyboard shortcuts

| Key | What it does |
|---|---|
| Space | Play or pause |
| F1 | This help |
| Ctrl+S | Save the show |
| Ctrl+O | Open a show |
| L | Leave the loop |
| Ctrl+Z, Ctrl+Y | Undo, redo (in the lyrics editor) |

Help > List Commands shows every command with its shortcut. On macOS, Ctrl is Cmd.
