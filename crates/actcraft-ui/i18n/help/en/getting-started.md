# Getting started

ActCraft is show control for live musicians: backing tracks with click, lyrics and sheet music,
setlists, MIDI and the lights, all on one clock and in one show file.

## Your first show

1. **Add songs.** Drag audio files onto the window, or press **Add songs…** in the library.
   Each file becomes a song; several files can be the tracks of one song.
2. **Play.** Pick a song in the library and press **Play** (Space). **Stop** goes back to the
   start.
3. **Save the show.** File > Save Show (Ctrl+S) writes one `.actcraft` file with everything.
