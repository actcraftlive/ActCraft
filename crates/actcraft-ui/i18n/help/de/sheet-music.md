# Noten für die Band

## Die Noten eines Songs

Der Reiter **Noten** zeigt ein PDF (**PDF anhängen…**) oder eine Partitur (**Partitur
anhängen…**: MusicXML oder eine MIDI-Datei). Eine Partitur erscheint als Noten und bei Gitarre
und Bass als Tabulatur, der laufende Takt ist markiert; **Wiedergabe folgen** hält ihn im Blick.
In einem PDF kannst du zeichnen, markieren und Notizen setzen.

**Noten aus der MIDI-Datei** schreibt die MIDI-Datei des Songs als Noten aus: Jede MIDI-Spur wird
eine Stimme (Schlagzeug nach General MIDI, Klavier auf zwei Systemen, Gitarre und Bass mit Tab).
MIDI aus einem Notenprogramm wird am besten; eingespieltes MIDI wird eher grob.

## Ein Notenblatt für jeden Musiker

1. Im Reiter Noten **Musiker** aufklappen und die Band anlegen: Kim, Alex …
2. Unter **Neues Notenblatt** einen Namen eingeben („Bass“) und **Notenblatt hinzufügen** drücken.
3. Bei **Für** wählen, für wen es ist, dann PDF oder Partitur anhängen. Das Blatt einer Partitur
   kann eine ihrer Stimmen zeigen.
4. Die Liste **Notenblatt** wechselt zwischen dem Hauptblatt und den anderen.

Ein Musiker sieht sein eigenes Blatt, sonst ein Blatt für alle.

## Notenblätter im Browser

Musiker können ihrem Blatt auf einem Tablet oder Laptop folgen:

1. Einstellungen > Band: **Musiker sehen ihre Notenblätter im Browser** anhaken. Adresse und Code
   stehen dort.
2. Auf dem Tablet diese Adresse im Browser öffnen (gleiches Netz), einmal den Code eingeben und
   den eigenen Namen wählen.
3. Die Seite zeigt dein Blatt zum laufenden Song und blättert mit.

Nur Rechner in deinem lokalen Netz kommen herein, und nur mit dem Code.
