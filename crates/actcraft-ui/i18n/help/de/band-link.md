# Bandverbindung

Mehrere ActCraft-Rechner können zusammen spielen: einer ist der Host, die anderen folgen ihm
(gleicher Song, starten und stoppen mit ihm). Jeder spielt seine eigene Kopie der Songs, und ein
Folgender spielt weiter, wenn der Host nicht mehr antwortet, er ist also auch ein Ersatzrechner.

## Einrichten {#setup}

1. Auf dem Host: Einstellungen > Band, **Bandmitglieder diesem Computer folgen lassen** anhaken. Ein
   Code erscheint.
2. Auf einem Folgenden: Einstellungen > Band, die Adresse des Hosts und den Code eingeben,
   **Folgen**.

Nur Rechner im lokalen Netz können folgen, und nur mit dem Code. Ein Folgender findet den Song des
Hosts über seinen Titel.
