# Tastenkürzel

| Taste | Was sie tut |
|---|---|
| Leertaste | Abspielen oder Pause |
| F1 | Diese Hilfe |
| Strg+S | Show speichern |
| Strg+O | Show öffnen |
| L | Schleife verlassen |
| Strg+Z, Strg+Y | Rückgängig, wiederholen (im Songtext-Editor) |

Hilfe > Befehle auflisten zeigt jeden Befehl mit seinem Kürzel. Unter macOS ist Strg die
Befehlstaste.
