# Erste Schritte

ActCraft ist Showsteuerung für Live-Musiker: Playbacks mit Klick, Songtexte und Noten, Setlisten,
MIDI und das Licht, alles auf einer Uhr und in einer Showdatei.

## Deine erste Show

1. **Songs hinzufügen.** Audiodateien auf das Fenster ziehen oder in der Bibliothek
   **Songs hinzufügen …** drücken. Jede Datei wird ein Song; mehrere Dateien können die Spuren
   eines Songs sein.
2. **Abspielen.** Einen Song in der Bibliothek wählen und **Abspielen** drücken (Leertaste).
   **Stopp** springt an den Anfang zurück.
3. **Show speichern.** Datei > Show speichern (Strg+S) schreibt alles in eine `.actcraft`-Datei.
