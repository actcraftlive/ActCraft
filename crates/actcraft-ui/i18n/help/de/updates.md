# Updates

Hilfe > Über ActCraft > **Nach Updates suchen** fragt GitHub, ob es eine neuere Version gibt. Vor
diesem Klick wird nichts gesendet.

Gibt es eine, bietet ein Fenster sie an: **Später** schließt es, **Herunterladen** öffnet die
Release-Seite und **Aktualisieren und neu starten** lädt sie herunter und installiert sie, nur
wenn du das wählst. Eine Testversion (Alpha) bekommt neuere Testversionen angeboten, eine fertige
Version fertige Versionen.
