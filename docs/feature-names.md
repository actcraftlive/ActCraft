# Feature names

Names users see, and how they were chosen ([naming rules](https://github.com/storytold/craft-contrib/blob/main/standards/naming.md)).
All names below are plain descriptive words; none has had the full trademark register search yet
(rule 4). The first pull request that ships a name to users runs that check and records it here.

| Name | Where | Status |
|---|---|---|
| Mixer, Track, Output bus, Mute group | Main window | Plain words, check pending |
| Metronome, Count-in, Visual only | Transport | Plain words, check pending |
| Library, Playlist, Set, Smart playlist, Queue, Play next | Sidebar | Plain words, check pending |
| Remote control | Status line (JSON control channel) | Plain words, check pending |
| Fixtures, Fixture type, Patch, DMX monitor | Lighting menu | Plain words, check pending |
| USB interface | Settings > Lighting | Plain words, check pending |

Compatibility names that stay as they are: MIDI, MTC, MIDI Clock, OSC, Art-Net, sACN/E1.31, OS2L,
ChordPro, LRC, PDF, WAV, FLAC, MP3, Philips Hue, MCP, Open Fixture Library (the open fixture file
format ActCraft imports; named only as the source of a file, never as a feature of ActCraft), DMX USB
Pro (the serial protocol of USB DMX interfaces; named only to say which interfaces work, never as a
feature of ActCraft).
