# Security

Please report a vulnerability privately through this repository's
[security advisories](https://github.com/actcraftlive/ActCraft/security/advisories/new)
("Report a vulnerability"), never in a public issue or pull request.

Say what is affected, how to reproduce it and what an attacker could do. You will get an answer
on the advisory.

ActCraft's network-facing parts are the local JSON control channel (loopback only, optional
token) and, in later milestones, the band network, OSC, Art-Net and sACN. Reports about those
are especially welcome.
